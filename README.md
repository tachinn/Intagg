# Intagg

Intagg is a simple aggregator platform that collects and displays opportunities like internships, fellowships, and hackathons from multiple platforms in one place.


## 🔗 Platforms Covered

* Internshala — available
* Unstop — available
* Naukri — ongoing
* Indeed — ongoing
* LinkedIn Jobs — planned

---

## 🚀 Live Website

https://intagg-backend.onrender.com/

---

## 🏗️ Architecture

### Frontend

* HTML, CSS, JavaScript

> Built mostly by experimenting and figuring things out along the way (aka vibe coding)

---

### Backend

* Python (Flask)
* PostgreSQL database (Neon Tech)
* Hosted on Render

> Implemented with some help from AI tools for structuring APIs and database handling
